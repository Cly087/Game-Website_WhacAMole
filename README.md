# WAM! (Whack-A-Mole)

A simple browser-based Whack-A-Mole game built with HTML, CSS, JavaScript, and the Canvas API.

This project was created as a small frontend development project to explore JavaScript game logic, canvas rendering, and DOM interactions.

## About the Game

Whack-A-Mole is a classic arcade-style game where players try to hit as many moles as possible before time runs out.

The game features a simple interface and interactive gameplay, recreated using vanilla web technologies.

## Built With
- HTML5 – Game structure
- CSS3 – Styling and layout
- JavaScript – User registration, game logic and interactions
- Canvas API – Game rendering and visual elements

## Features
- Registration and login functionality
- Classic Whack-A-Mole gameplay
- Interactive game elements
- Score tracking
- Countdown timer
